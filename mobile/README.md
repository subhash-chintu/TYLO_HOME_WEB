# Form & Foundry mobile starter

A minimal Expo and React Native placeholder app for iOS and Android. It currently has a Home screen with an empty catalog state, plus Categories and Help / Contact tabs. It uses the same simple black and white storefront direction. Product data and shopping links are not connected yet.

## Run locally

1. Install Node.js (LTS) and npm.
2. From this folder, install dependencies:

   ```sh
   npm install
   ```

3. Start Expo:

   ```sh
   npm start
   ```

4. Open the project in Expo Go on a device, or use the terminal shortcuts `npm run android` / `npm run ios` with the relevant simulator or development environment set up.

The same React Native app project can target both iOS and Android. iOS simulator builds require macOS; Expo Go on a physical device is suitable for an initial preview.
